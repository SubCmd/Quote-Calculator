# ADR-0016. 견적서 출력은 인쇄 전용 페이지로 하고, 공급자 정보는 환경변수에서 읽는다

- 상태: 수락됨
- 날짜: 2026-10-07
- 관련: F-5-1, Q-6, ADR-0002, ADR-0005, ADR-0013

> **보완: ADR-0039 · ADR-0040.** 인쇄 견적서의 **공급가액·세액 병기는 없앴다.**
> 금액은 현금가 하나다. 고객이 읽는 제목도 `견적서` 에서 `컨쇼 플랜` 으로 바뀌었다.
> 서식·발행처 환경변수·연락처를 넣지 않는다는 결정은 그대로다.

## 배경

F-5-1 은 견적서를 PDF 로 내려받을 수 있어야 한다고 적혀 있고, Q-6(서식·필수 표기 항목)은
미확정으로 남아 있었다. 만드는 방법이 셋 있었다.

1. 서버에서 헤드리스 브라우저로 PDF 파일 생성
2. PDF 라이브러리로 좌표를 직접 그리기
3. **인쇄 전용 페이지**를 만들고 브라우저의 인쇄 → PDF 저장을 쓰기

견적서에는 발행처(상호·사업자번호·대표자·연락처)가 들어가야 하는데, 그 값은 코드에 둘 수 없다.

## 결정

**`/q/[publicId]/print` 인쇄 전용 페이지를 만들고, 공급자 정보는 환경변수에서 읽는다.**

- 금액은 **저장된 스냅샷을 그대로** 쓴다. 출력 시점에 다시 계산하지 않는다. (ADR-0002)
- 공급자 정보는 `QUOTE_SUPPLIER_*` 환경변수로 받는다. **설정된 항목만 표기한다.**
  값이 없다고 출력을 막지 않는다. 금액은 환경변수와 무관하게 맞아야 한다.
- 표기 항목: 발행처 · 견적번호 · 발행일 · 유효기간 · 선택 항목별 금액 → 소계 → 할인 → 총액,
  그리고 **공급가액·세액**을 `tax.ts` 역산으로 병기한다. 총액에 세액을 더하지 않는다. (ADR-0005)
- **고객 연락처는 견적서에 넣지 않는다.** 수신처 칸을 만들지 않는다.
- 인쇄 버튼과 화면 장식은 `@media print` 에서 숨긴다. 인쇄물에는 견적서만 남는다.
- 만료된 견적도 출력은 막지 않되, 발행 당시 금액이라는 안내를 함께 인쇄한다. (ADR-0012)

## 이유

- **의존성이 늘지 않는다.** 헤드리스 브라우저는 배포 이미지에 바이너리를 끌고 오고,
  PDF 라이브러리는 한글 폰트를 직접 임베드해야 한다. 서식을 한 번 고칠 때마다 비용이 붙는다.
  인쇄 페이지는 지금 쓰는 것과 같은 HTML·CSS 라서 서식 수정이 화면 수정과 같은 일이 된다.
- **저장은 어차피 브라우저가 한다.** 사용자가 받고 싶은 것은 PDF 파일이고,
  인쇄 대화상자의 "PDF로 저장"이 그 일을 한다. 서버가 파일을 만들어야 할 이유는
  이메일 발송·보관인데 둘 다 아직 범위에 없다(F-5-2 미확정).
- **공급자 정보는 관리자가 고칠 값이 아니다.** 상호·사업자번호는 가격 규칙처럼 자주 바뀌지 않는다.
  DB 테이블과 편집 화면을 만들면 모델·마이그레이션·권한이 따라붙는데, 바뀌는 빈도가 그 비용을 정당화하지 않는다.
- **견적서에 연락처를 넣지 않는 쪽이 안전하다.** 조회 주소는 인증이 없다(ADR-0013).
  링크가 흘러가면 견적서가 통째로 보이는데, 거기에 이름·전화번호까지 있을 이유가 없다.
  금액을 제시하는 데 필요하지 않다.

## 하지 않기로 한 것

- **서버 PDF 파일 생성·이메일 발송.** F-5-2 가 미확정이다. 필요해지면 같은 HTML 을 입력으로 쓸 수 있다.
- **견적서 번호 체계 신설.** `publicId` 를 견적번호로 그대로 쓴다. 추측 불가능한 값이라 겸용해도 된다.
- **도장·로고 이미지 삽입.** 파일 업로드·보관이 따라붙는다. 요구로 나오면 그때 정한다.
- **공급자 정보 미설정 시 출력 차단.** 개발·테스트 환경에서 견적서를 못 보게 만들 뿐이다.

## 영향

- `.env.example` 에 `QUOTE_SUPPLIER_*` 자리를 남긴다. 운영 배포 전 채워야 한다.
- 서식을 바꾸는 작업은 CSS 수정이다. 별도 템플릿 엔진이 생기지 않는다.
- Q-6 은 이 문서로 해소된다. 다만 **인쇄물에 들어갈 법적 필수 문구**가 따로 있다면 추가 결정이 필요하다.
