# ADR-0015. 견적 검색은 기간·고객명으로 하고, 고객명 검색은 감사 로그를 남긴다

- 상태: 수락됨
- 날짜: 2026-10-07
- 관련: F-3-1, ADR-0012, ADR-0013, `.claude/rules/admin.md`

## 배경

관리자 견적 목록에는 상태 필터와 페이지네이션만 있다. F-3-1 은 **상태·기간·고객명**으로
검색할 수 있어야 한다고 적혀 있다.

여기에 걸리는 것이 둘 있다.

1. **고객명 검색은 개인정보 조회다.** 목록은 이름을 마스킹해 보여주는데(ADR-0013),
   검색어는 평문으로 받는다. 마스킹된 화면에서 이름을 평문으로 질의할 수 있게 되는 셈이다.
2. **기간의 경계를 어느 시각으로 볼 것인가.** 시각은 UTC 로 저장하는데(`.claude/rules/database.md`)
   담당자가 입력하는 `2026-10-01` 은 한국 날짜다.

## 결정

**상태·기간·고객명으로 검색하고, 고객명 검색은 실행할 때마다 감사 로그를 남긴다.**

- 검색 조건은 모두 **쿼리 파라미터**에 둔다. 주소를 공유·북마크할 수 있어야 한다(`.claude/rules/ui.md`).
- 고객명은 **부분 일치**(대소문자 무시)로 찾는다. 성만 아는 경우가 실무에서 흔하다.
- 고객명 검색이 포함된 조회는 `QUOTE_SEARCHED` 로 **검색어와 결과 건수**를 기록한다.
  상태·기간만으로 거르는 조회는 개인정보 조회가 아니므로 기록하지 않는다.
- **목록의 표시는 그대로 마스킹한다.** 검색으로 찾아도 전체 이름은 상세에서만 보이고,
  상세를 열면 기존대로 열람 기록이 남는다.
- 기간은 `calculatedAt` 기준이다. 목록에 "요청 일시"로 보여주는 값과 같아야 한다.
- 기간 경계는 **KST(+09:00) 고정 오프셋**으로 해석한다. `from` 은 그날 00:00:00,
  `to` 는 **다음 날 00:00:00 미만**으로 둔다. 종료일을 포함하지 않으면 담당자가 "오늘"을 넣었을 때
  오늘 건이 안 나온다.
- 검색 결과도 페이지네이션한다. 조건이 붙었다고 무제한 조회로 바꾸지 않는다.

## 이유

- **검색어를 남기지 않으면 감사 로그에 구멍이 생긴다.** 상세 열람은 기록되지만,
  "누가 어떤 이름을 찾아봤는가"는 상세를 열지 않으면 흔적이 없다.
  이름으로 훑어보는 행위 자체가 개인정보 조회다.
- **부분 일치를 막아도 보호되지 않는다.** 완전 일치만 허용해도 이름을 아는 사람은 그대로 찾는다.
  막히는 것은 실무뿐이고, 대신 치르는 비용은 담당자가 상세를 여러 건 열어 보는 것이다.
  그쪽이 열람 기록을 더 많이 만들고 노출도 더 크다.
- **KST 고정 오프셋이 서버 타임존보다 안전하다.** 서버 설정에 결과가 끌려다니면
  같은 검색이 환경에 따라 다른 건수를 낸다. 한국은 서머타임이 없어 `+09:00` 이 흔들리지 않는다.
- `new Date("2026-10-01")` 은 UTC 자정으로 해석된다. 그대로 쓰면 KST 기준 오전 9시가 되어
  그날 오전 건이 빠진다. 경계는 손으로 만들지 않고 한 함수에 가둔다.

## 하지 않기로 한 것

- **전화번호·이메일 검색.** F-3-1 에 없다. 식별력이 이름보다 높아 정책을 더 세게 잡아야 하고,
  필요해진 적이 없다.
- **이름 암호화·해시 후 검색.** 부분 일치가 불가능해지고, 지금 보관하는 값은 연락 수단뿐이다(ADR-0013).
  보호 수단은 마스킹 + 열람 기록으로 이미 정해 두었다.
- **검색 결과 CSV 내보내기.** 개인정보 내보내기는 별도 감사 대상이다(`.claude/rules/admin.md`).
  요구로 나오면 그때 따로 만든다.
- **자동완성·최근 검색어 저장.** 브라우저에 고객 이름이 남는다.

## 영향

- `AuditAction` 에 `QUOTE_SEARCHED` 가 필요하다.
- 감사 로그에 **검색어가 그대로 저장된다.** 로그 자체가 개인정보를 담게 되므로,
  감사 로그 화면도 보호 대상 안에 있다는 점이 분명해진다.
- 기간 경계 해석은 순수 함수로 두고 테스트한다. 서버 타임존에 의존하지 않는다.
